# Human interaction measurement

No live everyday-development workflow was performed, so no real intervention-rate
claim is possible. Mock fixtures exercise explicit bounded sharing/command grants,
reused grants, denial, correction, failover and recovery without manual prompt copying.
The actual tests validate enforcement, not first-run user effort or real provider behavior.

During this audit: one initial scope clarification (V5 found independently in local
refs before a reply), one permitted isolated pip downloader, one declined Playwright
installation, and sandbox permission requests for loopback performance/regression. A later
installed-Chrome escalation did not complete; the waiting review turn was interrupted.
No provider credential request, live cost approval or client-project authorization.
These audit-environment interactions are not product-workflow intervention metrics.

Pilot measurement must count initial setup, routine grants, repeats, security decisions,
provider changes, reconciliation, context restoration and verification separately.
Do not remove review or approval gates merely to improve this count.
